# Tema 3: Primeros Auxilios y Planes de Emergencia

## 📌 Resumen Rápido

Los **primeros auxilios** son técnicas inmediatas ante accidentes. La conducta **PAS** (Proteger, Avisar, Socorrer) guía la actuación. Los **planes de emergencia** establecen protocolos de evacuación y señalización. Los simulacros son obligatorios. La **RCP** (Reanimación Cardiopulmonar) puede salvar vidas.

---

## 1. Riesgos Psicosociales (Sesión 5)

### ¿Qué son?

Condiciones del trabajo que afectan la **salud mental y emocional**.

### Tipos Principales

| Riesgo | Descripción |
|-------|------------|
| **Estrés** | Tensión por sobrecarga, falta de control |
| **Burnout** | Agotamiento crónico, despersonalización |
| **Mobbing** | Acoso laboral repetido |
| **Carga mental** | Exceso de concentración |

### Medidas Organizativas

| Medida | Descripción |
|--------|-------------|
| **Variedad de tareas** | Evitar monotonía |
| **Autonomía** | Capacidad de decisión |
| **Clima laboral positivo** | Respeto y comunicación |
| **Pausas regulares** | Descanso mental |
| **Reconocimiento** | Feedback constructivo |

---

## 2. Plan de Emergencia (Sesión 6)

### ¿Qué es?

Protocolo organizado para actuar ante emergencias (incendio, fuga, accidente grave).

### Obligación Legal

RD 393/2007 - Normas básicas de autoprotección

### Componentes del Plan

| Componente | Descripción |
|------------|-------------|
| **Evaluación de riesgos** | Identificar posibles emergencias |
| **Medios de protección** | Extintores, BIE, detectores |
| **Organización interna** | Equipos de emergencia |
| **Procedimientos** | Antes, durante, después |
| **Señalización** | Rutas, salidas, equipos |

### Colores de Señalización

| Color | Significado |
|-------|-------------|
| 🔴 Rojo | Prohibición, incendio |
| 🟢 Verde | Salidas, equipos de救援 |
| 🔵 Azul | Obligación |
| 🟡 Amarillo | Advertencia |

## 3. Actuación en Emergencia (Sesión 7)

### Fases de Actuación

```
┌─────────────────────────────────────┐
│ ANTES (Prevención)                 │
│ - Mantenimiento equipos            │
│ - Simulacros periódicos             │
│ - Formación trabajadores           │
├─────────────────────────────────────┤
│ DURANTE (Evacuación)               │
│ - Mantener la calma                │
│ - Activar alarma                   │
│ - Seguir instrucciones             │
│ - Usar rutas señalizadas            │
│ - NUNCA usar ascensores            │
├─────────────────────────────────────┤
│ DESPUÉS (Evaluación)               │
│ - Recuento de personas              │
│ - Atención a heridos               │
│ - Comunicación servicios           │
│ - Actualizar plan                  │
└─────────────────────────────────────┘
```

### Roles en Emergencia

| Rol | Función |
|-----|---------|
| **Jefe de intervención** | Coordena la actuación |
| **Guía de ruta** | Guía durante evacuación |
| **Responsable de evacuación** | Controla punto de encuentro |

## 4. Primeros Auxilios - PAS (Sesión 8)

### Conducta PAS

```
PAS
├── P → PROTEGER
│   └── Garantizar seguridad del entorno
├── A → AVISAR
│   └── Llamar a emergencias (112)
└── S → SOCORRER
    └── Prestar ayuda inicial
```

---

## 5. Técnicas de Primeros Auxilios (Sesión 8)

### Botiquín de Empresa

| Material | Uso |
|----------|-----|
| Gasas estériles | Curar heridas |
| Vendas | Fijar apósitos |
| Guantes | Protección |
| Tijeras | Cortar vendas |
| Antisépticos | Desinfectar |
| Esparadrapo | Fijar apósitos |

### PLS (Posición Lateral de Seguridad)

Para personas **inconscientes que respiran**:
- Mantiene vía aérea despejada
- Previene atragantamiento
- Permite respirar

### RCP (Reanimación Cardiopulmonar)

En **parada cardiorrespiratoria**:

```
30 compresiones torácicas
        ↓
2 ventilaciones
        ↓
Repetir hasta llega ayuda
```

- Ritmo: 100-120 compresiones/minuto
- Profundidad: 5-6 cm (adulto)
- Número de emergencias: **112** (Europa)

## 🧠 Conceptos Clave para Examen

1. **Riesgos psicosociales** = estrés, burnout, mobbing
2. **Plan de emergencia** = protocolo organizado
3. **Simulacros** = parte fundamental
4. **PAS** = Proteger, Avisar, Socorrer

7. **RCP** = 30 compresiones + 2 ventilaciones
8. **Señalización** = roja/verde/azul/amarillo

10. **Nunca ascensores** en emergencias

## ⚠️ Errores Comunes

| Error | Realidad |
|-------|----------|
| "Correr en emergencias" | Mantener calma, seguir rutas |
| "EPIs bastan" | Medidas colectivas primero |
| "En emergencias, ascensor" | NUNCA usar ascensor |
| "Solo personal médico ayuda" | Cualquiera puede socorrer |

---

## ✅ Conclusión Fácil de Recordar

1. **Prevención psicosocial = buena organización**
2. **Plan escrito ≠ plan funcionando** → simulacros
3. **PAS salva vidas**
4. **RCP basics everyone debe conocer**
5. **112 → número de emergencias**
