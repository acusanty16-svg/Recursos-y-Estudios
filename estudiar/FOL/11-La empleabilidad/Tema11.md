# Tema 11: La Empleabilidad

## 📌 Resumen Rápido

La **empleabilidad** es la capacidad de mantenerse activo y atractivo para el mercado laboral. Se construye mediante **lifelong learning** (aprendizaje permanente), el dominio de **heramientas** para buscar empleo y el conocimiento de las **fuentes** de empleo disponibles.

---

## 1. Lifelong Learning y Herramientas (Sesión 24)

### ¿Qué es la Empleabilidad?

Capacidad de adaptarse, aprender y demostrar valor en cualquier contexto laboral. No es solo conseguir un empleo, sino mantenerse activo.

### Lifelong Learning

Aprendizaje permanente a lo largo de la vida.

| Tipo | Descripción |
|------|-------------|
| **Formal** | FP, universidad, master's |
| **No formal** | Cursos online, talleres, certificaciones |
| **Informal** | Experiencia, autoaprendizaje |

### Upskilling vs Reskilling

| Concepto | Descripción |
|----------|-------------|
| **Upskilling** | Mejorar habilidades actuales |
| **Reskilling** | Adquirir nuevas competencias (cambiar sector) |

### Herramientas para la Empleabilidad

| Herramienta | Descripción |
|-------------|-------------|
| **Formación continua** | MOOCs, certificaciones |
| **Idiomas** | Clave en mercado globalizado |
| **Competencias digitales** | Software, análisis, redes |
| **Portafolio** | Recopilar proyectos y logros |
| **Networking** | Red de contactos profesionales |

### Ejemplo: Bootcamps

En tecnología, muchas empresas contratan perfiles sin carrera universitaria pero con bootcamps, proyectos en GitHub y disposición para aprender.

## 2. Fuentes de Empleo y ETT (Sesión 25)

### Fuentes de Empleo

| Fuente | Descripción |
|--------|-------------|
| **SEPE** | Servicios públicos de empleo |
| **Portales online** | InfoJobs, LinkedIn, Indeed |
| **Redes sociales** | Contacto directo con reclutadores |
| **Ferias de empleo** | Eventos con ofertas y empresas |
| **Autocandidatura** | CV directo a empresas |

### Empresas de Trabajo Temporal (ETT)

**Definición**: Intermediate que contratan al trabajador y lo ceden temporalmente a otra empresa.

| Característica | Descripción |
|----------------|-------------|
| **Contrato** | Con la ETT |
| **Salario** | ETT determina |
| **Cotización** | La ETT cotiza a SS |

| Ventajas | Inconvenientes |
|----------|----------------|
| Primera experiencia | Menos estabilidad |
| Acceso rápido | Contratos más cortos |

### Headhunters y Consultoras

- Seleccionan candidatos qualificados para puestos específicos
- Enfpocan en perfiles medios/altos o especializados

> **Caso LinkedIn**: Más del 80% de reclutadores usan LinkedIn para buscar candidatos
